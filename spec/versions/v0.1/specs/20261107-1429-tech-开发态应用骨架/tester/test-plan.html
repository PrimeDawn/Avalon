1. 测试目标和范围

证明 SPEC-001 能从可复现安装启动真实 Electron，渲染 React，完成最小 IPC，验证开发更新与退出。覆盖 FR-001 至 FR-005，不验收小说内容、文件保存、最终视觉或 Windows 分发包。

2. 环境与启动

  • Windows x64 交互桌面；Node 24.18.0 / npm 11.16.0 为探索快照，执行时重新记录实际版本及锁文件指纹。
  • 无账户、无真实书稿、无远程服务。UI 样例只用 Avalon 名称与本地版本。
  • 开发地址 http://127.0.0.1:51735178，默认窗口 1000×700；Playwright 启动本项目 Electron 及 out/main/index.cjs，实际加载构建 HTML。
  • npm ci → npm run typecheck → npm run test:unit → npm run build → npm run test:e2e；开发态另运行 npm run dev。所有脚本在实现阶段创建。
  • E2E 单 worker、retries=0、每用例最长 30 秒；等窗口 / 可见文本 / IPC 事件，禁止固定 sleep 代替状态判断。
