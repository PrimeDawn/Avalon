4. 过程问题

  • Electron 45 npm 包惰性下载运行时。首次下载耗时，改用 @electron/get 的自定义 curl 下载器从同一 GitHub 官方文件续传；官方包内 SHA-256 校验通过，node node_modules/electron/install.js 退出 0。先前文件后来发现已有部分数据，不能据最初 0 字节观察断言内置下载器故障。
  • Node 配置下的 React 聚焦测试需要 Window 声明；补入 env.d.ts 后类型检查通过。原生事件替身显式跨 unknown 边界，不放宽生产代码 strict。
  • 超时 RED 测试的失败路径最初留下未等待断言；改为捕获 outcome 后断言，重新取得无未处理错误的 RED。测试层级仍待 tester 审核。
