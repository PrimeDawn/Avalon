EXP-004 · Electron关闭中间态不能只检查销毁状态

关键词：Electron, close, isDestroyed, ERR_FAILED

困境：加载中关闭窗口时，close 事件早于原生销毁。loadFile 已拒绝，但 isDestroyed 仍为 false，导致正常关窗被当作启动失败。

策略：先记录关闭请求，加载取消只在关闭过程中返回 null；其余加载错误继续交错误处理。用真实 Electron 事件时间线和正常关闭对照定位；单测显式覆盖 close 后、destroyed 前的中间态。

边界：当前窗口没有取消 close 的逻辑。后续未保存保护若 preventDefault，应重新核对关闭状态的语义，不能机械复用单向布尔标志。

依据：debugger/debug-002.html / debug-002-fix.html；与 EXP-003 的启动器 ExitCode=null 是不同根因。

EXP-005 · NSIS安装目录检查应先于卸载旧版

关键词：NSIS, electron-builder, 目录预检, 错误提示

困境：electron-builder 26.18.0 提取宏对复制失败统一提示 appCannotBeClosed；不可写目录被误报为程序无法关闭，标准重装流程已先移除旧版。

策略：先解析最终目标目录，以唯一临时文件实际验证创建、写入和删除，再进入标准安装段。向导失败页允许返回；静默路径也执行同样检查。以拒写目录、文件占位、可写对照及阶段标记验证不会提前进入安装。

边界：不修改依赖模板，不重复实现旧版卸载；预检不等于事务回滚，也不能保证预检后权限变化或磁盘满仍安装成功。

依据：build/install-directory.nsh / build/installer.nsh；debugger/debug-002.html。
