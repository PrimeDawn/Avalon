4. 遇到的问题

  • asar 检查脚本首次使用斜杠文件名，在 Windows 库调用中无法读取文件；改为原生路径分隔符后检查通过。失败日志保留，产品包未因此修改。
  • 打包器提示未配置作者与图标，使用默认图标；没有签名证书，安装包和应用 exe 均为 NotSigned，符合用户接受的自用边界。
  • npm 全量审计报告 6 个 moderate 条目，来源为打包开发依赖链中的 minimatch；生产依赖审计为 0。未运行 audit fix 或擅自降级批准的打包器。Squirrel 的 electron-winstaller 安装脚本未批准执行，当前使用 NSIS 且构建成功。
