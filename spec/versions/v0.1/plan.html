2. 依赖与关键路径

关键依赖声明

无外部系统依赖。内部依赖：项目骨架 → 存储层 → 书库 → 导入；外壳 依赖骨架，编辑器 依赖存储层与外壳。关键路径为骨架 → 存储层 → 书库 → 导入。

3. 地基硬约束（验收逐条核）

  • 不写死任何路径：书库根、用户数据目录、临时目录、资源目录均运行时解析；架构上不得出现仅 Windows 可用的分支
  • 不写死任何业务枚举：章节状态、wiki 类型、技能种类走可扩展注册表，UI 内不硬编码
  • 模块以契约注册：后续能力经模块注册表挂载，新增模块不修改既有模块代码

4. 版本发布与交付标准

  • 全量单元测试与集成测试通过，零破坏性回归
  • 四个属性分类的入版 Spec 全部完工并经独立验证
  • 在干净的 Windows 上安装后，能新建一本书、手写三章、重启后内容原样
